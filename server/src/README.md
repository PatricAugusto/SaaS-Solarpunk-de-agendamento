# AgendaGlass ✨

SaaS de agendamento (estilo Calendly) com autenticação JWT, PostgreSQL e lógica de conflito de horários.

## Stack
- Backend: Node.js + Express + PostgreSQL
- Frontend: React + styled-components + date-fns
- Design: Liquid Glass + paleta Solarpunk (neons) + tipografia retro gaming

## Estrutura
- `/server` — API REST
- `/client` — Aplicação React
